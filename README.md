# The Wayfarer's Ledger

A self-contained Baldur's Gate 3 equipment checklist, organized by act.

Open `index.html` in a browser. No build step is required. Search, act filters, and saved checklist progress work without a server.

Location details and item images were checked against the linked [BG3 Wiki](https://bg3.wiki/) pages on September 14, 2026.
